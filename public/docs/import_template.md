# คู่มือ + แม่แบบไฟล์นำเข้าปีงบใหม่ (`import_<ปี>.json`) สำหรับ AI

ไฟล์นี้ใช้เมื่อหน้า **"นำเข้า / เปิดปีงบใหม่"** อ่านไฟล์ Excel ปีใหม่เองไม่ได้ (เช่น รูปแบบตารางเปลี่ยนมาก)
ให้ส่งไฟล์ Excel 2 ไฟล์ (**แบบฟอร์มเบิก ปี XXXX** + **ประมาณการ ปีงบ XX**) พร้อมคู่มือนี้ให้ Claude หรือ AI อื่น
แปลงเป็นไฟล์ `import_<ปี>.json` แล้วนำไฟล์นั้นไปอัปโหลดที่ขั้น 1 ช่อง (B)

> แนะนำ: แนบ **ไฟล์ข้อมูลตั้งต้นปัจจุบัน** ด้วย (แท็บ "ระบบ" → "ดาวน์โหลดข้อมูลตั้งต้นปัจจุบัน (JSON)")
> เพื่อให้ AI ใช้ **รหัสรายการเดิม** ได้ถูกต้อง — ไฟล์นั้นมีข้อมูลภายใน รพ. ให้ใช้กับ AI ที่หน่วยงานอนุญาตเท่านั้น

---

## 1. ไฟล์ต้องมีอะไรบ้าง

| key | จำเป็น | ความหมาย |
|---|---|---|
| `format` | ✔ | ต้องเป็นข้อความ `"pcu-supply-import/1"` ตรงตัว |
| `fy` | ✔ | ปีงบที่จะเปิด (พ.ศ. ตัวเลข เช่น `2571`) — ต้องเป็นปีงบปัจจุบัน + 1 |
| `pcus` | ✔ (แนะนำ) | รายชื่อ รพ.สต. `[{ "code", "name", "print_name", "group" }]` ใช้รหัสเดิมของระบบ (`PCU01` …) |
| `form` | ✔ | แบบฟอร์มของปีใหม่: `{ "fy", "note", "steps": [...] }` 1 step = 1 หน้า (1 แผ่นในไฟล์แบบฟอร์ม) |
| `plans` | ✔ | แผนรายปีของปีใหม่ `{ "<fy>": { "<รหัส รพ.สต.>": { "<รหัสรายการ>": [จำนวน OP, จำนวน PP] } } }` |
| `config` | ไม่บังคับ | เช่น `{ "plan_total": { "<fy>": { "op":…, "pp":…, "total":… } } }` = ยอด "รวมเป็นเงิน" ทั้งเครือข่ายจากไฟล์ (ระบบใช้ตรวจทาน) · งบ `budget_op`/`budget_pp`/`budget_total` |
| `verify` | ไม่บังคับ | `{ "plan_<fy>_per_pcu": { "<รหัส รพ.สต.>": { "op", "pp", "total" } } }` = แถว "รวมเป็นเงิน" ต่อแห่งในไฟล์ (ระบบแสดง ✓/✗ เทียบ) |
| `limits` | ไม่บังคับ | ถ้าไม่ใส่ ระบบคำนวณเพดานตั้งต้นให้เอง (ต่อปี = แผน OP+PP · ต่อเดือน = P90 รายเดือนของปีก่อน หรือ แผน/12×2) |

ไม่ต้องใส่ข้อมูลปีก่อน (`actual_prev`, `stats`, `prices_prev`) — ระบบดึงจากใบเบิกที่ส่งแล้วในปีงบปัจจุบันเอง

### หน้า (`form.steps[]`)
```
{ "code": "P1", "sheet": "แบบ พัสดุ 1", "title": "<ชื่อใบ แถวบนสุดของแผ่น>", "subject": "<ข้อความหลังคำว่า เรื่อง>",
  "to": "<ข้อความหลังคำว่า เรียน>", "dispense_unit": "พัสดุ", "rows": [ ... ] }
```
- `dispense_unit` = หน่วยที่จ่ายของหน้านั้น: `"พัสดุ"` · `"จ่ายกลาง"` · `"LAB"`
- `rows` เรียงตามไฟล์: หัวหมวด `{ "type": "section", "title": "…" }` (ไม่เกิน 2 หัวต่อหน้า) และรายการ
  `{ "type": "item", "code": "P1-01", "seq": 1, "name": "…", "unit": "…", "price": 34 }`
- รายการที่เปิดใช้ไม่เกิน **24 รายการต่อหน้า** · ไม่เกิน **10 หน้า**
- `name`, `unit` คัดตามไฟล์แบบฟอร์ม · `price` = **ราคาต่อหน่วยจากไฟล์ประมาณการ** (จับคู่ด้วยชื่อรายการ) เป็นตัวเลข ไม่มีคอมมา
- `seq` = เลขลำดับในไฟล์ (นับต่อเนื่องทั้งฟอร์ม)

### แผน (`plans`)
- อ่านจากแผ่นที่รวมทุก รพ.สต. (มักชื่อ "รวม") — ใต้ชื่อ รพ.สต. แต่ละแห่งมีคอลัมน์ OP / PP
- ใส่เฉพาะคู่ที่จำนวนไม่เป็น 0 ทั้งคู่ · จำนวนเป็นตัวเลข (จำนวนเต็มถ้าเป็นจำนวนเต็ม)
- ห้ามใช้คอลัมน์ "เป็นเงิน" เป็นจำนวน · แถว "รวมเป็นเงิน" ไม่ใช่รายการ (ใช้ใส่ `verify` / `config.plan_total` ได้)

## 2. กฎรหัสรายการ (สำคัญที่สุด)
1. **รายการเดิมใช้รหัสเดิมเสมอ** แม้ชื่อจะเขียนต่างไปเล็กน้อย หรือย้ายไปอยู่หน้าอื่น — รหัสเดิมผูกกับประวัติการเบิก เพดาน และสถิติ
2. **รายการใหม่** = รหัสหน้า + เลขถัดไปของหน้านั้น เช่น หน้า P3 มีรหัสสูงสุด P3-22 → รายการใหม่ได้ `P3-23` (ห้ามนำรหัสที่เคยใช้แล้วมาใช้ซ้ำ)
3. รหัสต้องไม่ซ้ำกันทั้งฟอร์ม · รูปแบบ `<รหัสหน้า>-<ตัวเลข 2–3 หลัก>`
4. รายการเดิมที่ไม่มีในไฟล์ปีใหม่ **ไม่ต้องใส่** — ระบบจะเก็บไว้เป็นรายการที่ปิดแล้วเอง
5. ถ้าไม่ทราบรหัส (ไม่ได้แนบไฟล์ข้อมูลตั้งต้นปัจจุบัน) ให้ใส่ `"code": ""` แล้วใน `plans` ใช้ key `"#<seq>"` แทนรหัส
   (เช่น `"#51": [10, 0]`) — หน้าเว็บจะพาไปขั้น "จับคู่รายการ" ให้ผู้ดูแลเลือกรหัสเอง

## 3. ตัวอย่าง (2 รายการ · 2 รพ.สต. — ข้อมูลสมมุติ)
```json
{
  "format": "pcu-supply-import/1",
  "fy": 2571,
  "generated_by": "AI (Claude) จากไฟล์ Excel 2 ไฟล์",
  "sources": ["แบบฟอร์มเบิก ปี 2571.xls", "ประมาณการ ปีงบ 71.xls"],
  "pcus": [
    { "code": "PCU01", "name": "รพ.สต.ตัวอย่าง ก", "print_name": "รพ.สต.ตัวอย่าง ก", "group": "ทั่วไป" },
    { "code": "PCU02", "name": "รพ.สต.ตัวอย่าง ข", "print_name": "รพ.สต.ตัวอย่าง ข", "group": "ทั่วไป" }
  ],
  "form": {
    "fy": 2571,
    "note": "นำเข้าจากไฟล์ Excel ปีงบ 2571",
    "steps": [
      {
        "code": "P1", "sheet": "แบบ พัสดุ 1", "title": "ใบเบิกวัสดุ (ตัวอย่าง)", "subject": "ขอเบิกวัสดุ (ตัวอย่าง)",
        "to": "ผู้อำนวยการโรงพยาบาล", "dispense_unit": "พัสดุ",
        "rows": [
          { "type": "section", "title": "วัสดุสำนักงาน" },
          { "type": "item", "code": "P1-01", "seq": 1, "name": "กระดาษตัวอย่าง A4", "unit": "รีม", "price": 120 },
          { "type": "item", "code": "P1-02", "seq": 2, "name": "ปากกาตัวอย่าง", "unit": "ด้าม", "price": 5.5 }
        ]
      }
    ]
  },
  "plans": {
    "2571": {
      "PCU01": { "P1-01": [12, 0], "P1-02": [24, 6] },
      "PCU02": { "P1-01": [6, 2] }
    }
  },
  "config": { "plan_total": { "2571": { "op": 2292, "pp": 273, "total": 2565 } } },
  "verify": { "plan_2571_per_pcu": {
    "PCU01": { "op": 1572, "pp": 33, "total": 1605 },
    "PCU02": { "op": 720, "pp": 240, "total": 960 }
  } }
}
```
(ตรวจ: PCU01 OP = 12×120 + 24×5.5 = 1,572 · PP = 6×5.5 = 33)

## 4. Prompt สำเร็จรูป (คัดลอกไปวางได้เลย)
```
แปลงไฟล์ Excel แนบ 2 ไฟล์เป็น import_<ปี>.json ตามรูปแบบในคู่มือ import_template.md ที่แนบมานี้
- ไฟล์ที่ 1 = แบบฟอร์มเบิกวัสดุ ปีงบใหม่ (1 แผ่น = 1 หน้า) → form.steps (ชื่อใบ เรื่อง เรียน หัวหมวด รายการ หน่วย ตามไฟล์)
- ไฟล์ที่ 2 = ประมาณการเบิกวัสดุ ปีงบใหม่ ใช้แผ่นที่รวมทุก รพ.สต. → ราคาต่อหน่วย (จับคู่ด้วยชื่อรายการ) และ plans (จำนวน OP/PP ต่อแห่ง)
- ไฟล์ที่ 3 (ถ้ามี) = ข้อมูลตั้งต้นปัจจุบันของระบบ → ใช้รหัสรายการเดิม (form.steps[].rows[].code) และรหัส รพ.สต. เดิม (pcus)
  รายการเดิมต้องใช้รหัสเดิมแม้ชื่อเขียนต่างเล็กน้อย · รายการใหม่ = รหัสหน้า + เลขถัดไปของหน้านั้น
  ถ้าไม่แน่ใจว่าเป็นรายการเดิมหรือไม่ ให้ใส่ "code": "" และใช้ "#<seq>" เป็น key ใน plans แล้วบอกรายการนั้นท้ายคำตอบ
- fy = ปีงบใหม่ (พ.ศ.) · format = "pcu-supply-import/1" · ไม่ต้องใส่ข้อมูลปีก่อน
- ใส่ config.plan_total และ verify.plan_<fy>_per_pcu จากแถว "รวมเป็นเงิน" ของไฟล์ประมาณการ
- ตรวจก่อนส่ง: รหัสไม่ซ้ำ · ≤ 24 รายการต่อหน้า · ≤ 2 หัวหมวดต่อหน้า · ราคาเป็นตัวเลข · ผลรวม จำนวน×ราคา ต่อแห่ง เทียบกับแถว "รวมเป็นเงิน"
  (ถ้าไม่ตรง ให้รายงานแห่งที่ต่าง — อย่าแก้ตัวเลขให้ตรง)
- ตอบกลับเป็นไฟล์ JSON ไฟล์เดียว (UTF-8) ชื่อ import_<ปี>.json พร้อมสรุปสั้น ๆ: จำนวนหน้า/รายการ · รายการใหม่ · รายการที่หายไป · ยอดรวมเครือข่าย
```

## 5. หลังได้ไฟล์
1. หน้า "นำเข้า / เปิดปีงบใหม่" → ขั้น 1 ช่อง (B) เลือกไฟล์ `import_<ปี>.json` → ระบบตรวจรูปแบบทันที
2. ทุกรายการมีรหัส → ข้ามไปขั้น 3 · ถ้ามีรายการที่ไม่มีรหัส → ขั้น 2 เลือกจับคู่
3. ขั้น 3 ตรวจยอดแผนต่อ รพ.สต. (✓/✗ เทียบไฟล์), รายการใหม่/ปิด/ราคาเปลี่ยน → กด **"เปิดปีงบ <ปี>"** และพิมพ์ยืนยัน
